GitHubへ直接保存

未接続・編集ツール内に認証情報は保存されません

初回にGitHubの限定トークンが必要です。rnnrリポジトリだけに「Contents: Read and write」を許可してください。入力したトークンはこの画面が開いている間のメモリでのみ使用し、HTML・バックアップ・端末のストレージには保存しません。

保存先：mlpys0/rnnr の main ブランチ。HTMLは更新前に最新版と照合して上書き事故を防ぎます。画像は images/ファイル名 に直接保存されます。反映に少し時間がかかる場合があります。

従来のHTML書き出し・JSONバックアップも使えます。GitHubに直接保存する場合は、まず「公開中のページを読み込む」でGitHub最新版を取得してください。画像をアップロードした後は、表示する画像パスも設定し、HTMLを保存してください。

使い方・注意事項

① GitHubに接続 → ② 表／裏を選んで「公開中のページを読み込む」 → ③ 編集 → ④ 「GitHubに保存して公開」で完了。トークンを使いたくないときは、従来どおりHTML書き出しも可能です。

文章の太字や改行はそのまま保存できます。画像は「画像をアップロード」、または各画像欄の「この画像をアップロード」からGitHubへ送れます。画像変更後はHTMLも保存してください。

編集ツール単体は書き込み権限を持ちません。あなたが限定トークンで接続した場合のみ更新できます。トークンは誰にも送らず、コード・GitHubリポジトリ・チャットへ書かないでください。秘密ページのHTMLは公開リポジトリの閲覧者に読めるため、年齢確認はアクセス制限にはなりません。

GitHubへ保存済みのHTMLは、別の端末で「公開中のページを読み込む」を押すと取得できます。編集中の未公開データは自動同期しません。途中で切り替えるときはバックアップをご利用ください。
